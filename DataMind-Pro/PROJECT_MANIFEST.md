# Project Manifest

This package is ready for GitHub upload.

## Main Deliverables

- `index.html`: production single-file app. Open directly in a browser or publish with GitHub Pages.
- `DataMind-Pro-single-file.html`: same finished product as one portable file.
- `data/sample-business-finance.csv`: sample CSV used for reports and Notebook.
- `reports/sample-analysis-report.pdf`: PDF report generated from the sample CSV.
- `reports/sample-analysis-report.html`: printable HTML version of the same report.
- `notebooks/datamind_analysis.ipynb`: Jupyter Notebook showing reproducible analysis logic.
- `scripts/generate-assets.mjs`: source script that regenerates the report and Notebook.

## GitHub Pages

Upload this folder to a GitHub repository and enable Pages from the repository root. GitHub Pages will serve `index.html` automatically.

## Single-File Distribution

For simple distribution, send only:

```text
DataMind-Pro-single-file.html
```

It contains the finished app UI and business logic in one file.
